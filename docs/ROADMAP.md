# RoadWeaver 重制版的下一阶段

当前代码状态见[开发现状](STATUS.md)，旧版证据见[功能对照](FEATURE-PARITY-CHECK.md)。本路线讨论还没完成的事。

旧版用来查施工承诺和功能退化。重制版的评价标准是：更常交付可建、可通行、能共享关键基础设施的路网；减少无用采样、寻路和区块任务等待。

| 范围 | 旧版 | 重制版要怎么超越 |
|---|---|---|
| 选线 | 势场 A* 对每条路扩展节点，地形、群系、避让、优惠和形状旋钮混在步进代价里，最后再修形 | 保留 FMM、DP 和弹性带；明示硬通行约束，记录并校准施工代价，不再叠旧版权重 |
| 选网 | 成路后再判并排、共用、合流 | 测地拓扑先选端点边，但 PipelinePlanner 传入 ObstacleField.NONE。下一步应让能否建造、能否共用渡口影响入选 |
| 施工 | 模板和程序化建造桥梁、隧道、陆地铺设与 NETWORK_REUSE | 两版调用均存在，复用既有建造能力，把同一份终态路线及区块占地交给施工 |
| 性能 | 历史的 215 秒来自旧版逐路搜寻的现场记录 | 不能与本轮纯内核毫秒数直接比较。应在同一存档、同一组连接拆分采样、拓扑、单路、区块编译和落块耗时 |

## 推荐顺序

1. **坐标口径（已完成离线验收，待真机）**。平地、step=8、源 (8,8)、目标 (34,19) 原先回溯首格偏到 (10,11)。现按真实采样格回溯，平滑后接独立校验的短边；负坐标、正反向、同格、保护列和对齐点序均有回归。见 [HANDOFF 第 6 轮](HANDOFF.md)。
2. **按可建性选网（粗格影子已接线，真实施工证据待采）。** PipelinePlanner 用高度和轴向坡度选树，Road 在后段才做桥隧、挖填和保护校验。同种子开启 `-Droadweaver.buildabilityShadow=on` 收集候选的测地成本、湿格、高程偏差和可共享湿格；只评入选边和有限候补，原拓扑不变。首批夹具已覆盖「近但难建」「两线能共用渡口」。现场比较施工后可通行道路、绕行、平行桥与挖填量；没有实际修建结果前不启用补边或换边。
   - 粗拓扑仅复用现有高度图，高度差只能作为湿列代理；`AsyncPlanningOps` 先产出 `incoming`，随后才准备结构快照，所以当前生产影子不出完整施工排名。日志 `gradeOnlyOrder` 仅按首尾弦线的高程偏差做对照；共享湿格不是共用桥梁的确认。以后应以同一连接标识关联后段的实际施工、保护校验，再决定要不要对有限候补做对应精算。
   - 每批最多评 12 边、4 条候补，按源复用回溯场，并按格数 × 最坏求解次数限额；超出预算写明原因。回归对照了开关关闭、评分成功和评分异常的相同拓扑及顺序。
3. **只决定一次横向几何（离线后真机 A/B）。** 分离选线与施工栅格化，先试只取消第二次陆地 relax；保留桥头加密、长桥正弦、保护列、道路宽度和站距约束。同一路径回放比较保护缺口、曲率、站距、桥头和落块；不能仅凭一次离线通过改默认。
4. **盯尾延迟（可离线起步）。** 先记录每路冻结格、队列入队和峰值、各阶段 p50/p95、区块任务最长等待。若队列分配主导，试原始数组小根堆，先等价复刻同权顺序并逐位对拍；若采样主导，优先在同一地形上下文共享只读瓦片。只有数据指向候选图过大才试分区和稀疏邻域，并复核合法替代边和连通性。
5. **分开道路身份和施工完工（先做重开对拍）。** PathFeature:241–242 用道路指纹判完工；RoadFingerprint 不读 targetY、spans 或占地列。保留现有身份和 schema 3，另外定义完工内容的比较策略。用同身份改坡或跨度、未改道路不重铺、现有台账重开验收；更新已经铺好的真实区块前用存档副本。
6. **更完整的方向代价（有 A/B 再设默认）。** 当前 x/z 轴向慢度不包含斜坡交叉项。先量化旋转后的同一斜坡、等高线和窄山口的方向误差，再试更丰富的迎风模板。验收看曲率、最大坡度和施工代价是否改善，保护冲突和尾延迟是否增加。

本轮保持 ProfileDpSource.crossing、跨度回写默认值、长桥正弦、村庄包围盒、QualityGate 阈值与存档格式。纯内核数据不外推世界加载和帧时间。现场样本应分首次生成、已有存档重开、Chunky 同时运行；分别记录计划、通过校验及实际落成的道路。

## 已有证据排除的尝试

| 尝试 | 停止理由 |
|---|---|
| 用单点群系预筛决定要不要查结构 | 历史 37,181 个探测位置中，有 33,288 个会被预筛拒绝；其中 769 个有真实结构起点。不能复刻原版多点采样。 |
| 整套桥掩码逐列细采 | 83 段水 / 4,538 站，整站全湿 88.8%，仅一列湿 1.9%。先针对有证据的错桥修复。 |
| 对齐计价和建造阈值 | 历史 63 次过水中，只有 1 次落在差异区间 `(12,20]`。 |
| 给结构解析加记忆化 | 既有样本 `uniqueStarts == total`，未发现可利用的重复解析。 |
| 开回 GPU 精确采样 | 整合包的精确密度图超过当时 4060 的 2,046 MiB 单缓冲上限，`clCreateBuffer -61` 后回落 CPU，拖住生成。粗采 GPU 是另一件事。 |

长桥弯、村庄包围盒、路肩开关和存档协议属于现有[开发约定](../CONVENTIONS.md)。`crossing` 解耦须先拿到新的真机跨度召回数据；用户确认前保持现状。
