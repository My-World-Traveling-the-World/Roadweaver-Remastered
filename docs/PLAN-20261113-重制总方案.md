## 〇、一句话总纲

**旧版的钱花在三处：寻路（215s）、结构解析（74s）、15 道互相打架的纵断面 pass（质量上限）。
新版用三个数学上更优的内核一次性换掉它们：测地场（FMM）换掉逐对 A*、全局 DP 换掉 pass 流水线、弹性带换掉 8 个后处理。**

| 目标 | 旧版 | 新版目标 | 手段 |
|---|---|---|---|
| **更高效的算法** | 23 次独立 A\*（215 s） | N 次场求解得 N×N 矩阵（秒级） | `GeodesicMatrix` + MST |
| **更快的加载** | 门开→道路 ≈ 10 min | **≤ 3 min** | 寻路提速 + 结构枚举预筛 + DP 单遍纵断面 |
| **更高的质量** | 38× 坡罚不对称 ⇒ ±8 锯齿；15 道 pass 互相覆盖 | 锯齿 ≤ ±2；约束在求解前进入 | 真 Finsler + DP 约束化 + 弹性带投影 |

三条目标不冲突：**算法换掉之后，加载和质量是同一件事的两面**（快是因为不求多余解，质量高是因为约束一次到位而不是事后修）。

## 一、现状盘点（钱花在哪儿）

### 1.1 真机耗时分布（旧版实测）

| 环节 | 耗时 | 占比 | 性质 |
|---|---|---|---|
| A\* 寻路（23 连接，step=8） | **215.5 s** | 粗规划 **98.1%** | 逐对重扫同一地形 |
| 结构起点解析（4374 个） | **74.4 s** | 异步规划 **53%** | **91.4% 解析完是空的** |
| 局部修复统一采样（17 路 43 窗） | 40.7 s | — | 33.7 万列，CPU |
| 粗采样本身 | 4.2 s | 1.9% | **不是瓶颈**（OpenCL 已在扛） |

**结论**：要压缩「门开 → 道路就绪」的总时长，杠杆排序是 **寻路 ≫ 结构解析 ≫ 其余**。
采样、写入、装饰都在噪声里，不值得动。

### 1.2 旧版质量上限的三个结构性来源

| 病根 | 表现 | 为什么改不动 |
|---|---|---|
| **A. 38× 坡罚不对称** | 正交步爬 1 格代价 8008.5，对角步 210.9 ⇒ ±8 锯齿是**全局唯一最优解** | 是代价函数的形式问题，调参救不了 |
| **B. 15 道 pass 互相打架** | 抬桥面→坡度失效→再贴坡→变桥→再贴甲板 | 顺序修补的结构问题，加 pass 只会更糟 |
| **C. 三套并行事实** | targetY / spans / 桥范围各算各的，靠事后校验收敛 | 没有权威中间表示，永远收敛不完 |

|---|---|---|
| `ProfileDpSolver`（纵断面 DP） | ✅ **已是默认**，含 deckFloor 水位约束、二阶坡度 | 6 项旧能力未搬（prefer-cut 等） |
| `ModeDpSolver`（桥隧联合 DP） | ✅ 内核完成 + 200 组暴力对拍 | **未接入生产** |

## 二、三个数学内核（为什么它们更优）

### 2.1 测地场替代逐对 A\* —— 解决「215 秒」

**旧版**：23 条连接各自跑 A\*，每条把同一片地形重新探索一遍。
**新版**：对每个结构节点跑**一次** Fast Marching（Eikonal 方程的 Godunov 迎风解），得到它到**全图每一点**的到达时间 ⇒ N 个节点 = N 次求解 = 完整 N×N 测地距离矩阵。

- 拓扑（MST）在矩阵上**免费**做，树的边天然不相交 ⇒ 旧版的三套事后并行检测器整个不需要。
- 复杂度：旧 O(连接数 × 每对 A\* 的探索量)；新 O(N × n log n)。实测规模下预计 **215 s → 秒级**。
- 风险：FMM 是全图求解，不剪枝；但 N≈24、n≈3 万（粗网格）时仍在百毫秒级。**已核实**。

### 2.2 全局 DP 替代 15 道 pass —— 解决「质量上限」

**旧版**：先按地形算剖面，再依次贴 15 道补丁（抬桥面、浅滩、相邻桥连续、峡谷稳定岸、针尖、1-2-1 平滑、GradeCap、山区分档、共享引道…），补丁互相覆盖。
**新版**：把每一项旧能力翻译成 DP 的**求解前约束**，一次求出满足全部约束的最优剖面。

已搬：`deckFloor[]`（桥面水位下界，`e82bea0`）。
待搬 6 项（见 §4 阶段 1）。**判据：不再出现「仅 LEGACY 分支生效」的能力。**

### 2.3 弹性带替代 8 个后处理 —— 解决「8 个 pass 修同一件事」

**旧版**：DP 简化 / Catmull-Rom / 1-2-1 平滑 / relax 拉回 / 锯齿检测 / 急弯冻结 / 窗口 splice / fine regenerate —— 8 个 pass 全在修「8 邻域折线」这一种 artifact。
**新版**：`ElasticBandSolver` 一次成型（连续曲线 + 保形权重），边界条件保证直线输入严格保持直线。

待补：把 `ObstacleField` 投影接进迭代（现在它不识障碍）。

### 2.4 真 Finsler 度量 —— 解决「38× 锯齿」

**旧版**：坡度罚按步收、基础代价按长度收 ⇒ 38× 不对称 ⇒ 锯齿是数学必然。
**新版**：`FinslerMetric.cost(x, θ̂) = 1 + λ_grade·(∇h·θ̂)² + λ_obs·V(x)`，坡度乘**方向分量**、按弧长积分 ⇒ 正交与对角天然同价。

现状：`cost()` **零调用**，FMM 只调 `isotropicCost` ⇒ 「Finsler」名不副实。接上就根治。

## 三、分阶段路线图（依赖驱动，非按域平铺）

> 铁律：**任何一阶段验收不过，停在该阶段，不许往下走。**
> 每阶段独立提交、独立可回滚、独立有守卫。

### 阶段 0：采集真实地形（前置，已被 S7 清单覆盖）

```
-Droadweaver.profileAb=on → 跑一局 → roadweaver-terrain-ab.tsv
→ 复制成 common/src/test/resources/profile/terrain-samples.tsv → .\verify.ps1
```
**通过标准**：样本 ≥ 20 且 DP 土方合计 ≤ 旧。**这是后面一切的地基，没数据不许动。**

### 阶段 1：DP 补完 6 项旧能力（质量主线）

| # | 能力 | 翻译成的束 | 影响面 |
|---|---|---|---|
| 1 | **prefer-cut**（绝不造天桥）| `CostModel` 的 fill/cut 权重反转，或 lo/hi 不对称窗口 | **每条路** |
| 2 | 浅滩两岸切平 | crossing 段的边界条件 | 过水 |
| 3 | 相邻桥甲板连续（gap≤24 后跨≥前跨） | 跨段约束 | 多桥 |
| 4 | 山区 cut/fill 分档（8/3 不能按 5/2 用） | 按地形分类喂不同 limits | 山地 |
| 5 | 共享引道（多站剖面共享） | 多站 pin 而非单点 | 端点 |
| 6 | 峡谷稳定岸 / 河岸跳变 / 针尖 / 1-2-1 / GradeCap | 后处理约束并入 DP | 局部 |

**验收**：`ProfileDpSourceTest` 从 3 个增至 ≥15 个（每项含负控）；`PASS tests=708` → ≥750。
**先做 prefer-cut**（影响每条路；两方案已在 §5.1 列出，待拍板）。

### 阶段 2：测地拓扑接入生产（速度主线 · 最大杠杆）

**改什么**：`NetworkPlannerFactory` 加第 8 种 `GEODESIC_MST`（不动默认 RNG），内部走 `GeodesicMatrix.build` → `MinimumSpanningTree.solve` → 对 MST 边逐条跑寻路。

**验收**：
- `coarse planning timing` 的 `pathfindingMs` 从 **215 s → < 5 s**；
- 路网无平行双路（MST 性质）；
- 旧 6 种算法原样保留可切回。

**风险与对策**：MST 是树、RNG 有少量环 ⇒ 路网形态会变。做成**可选新算法**，真机 A/B 后再定默认。

### 阶段 3：结构枚举群系预筛（速度主线 · 第二杠杆）

**旧版教训**：R-07 用单点 `getNoiseBiome` 被判死（769 个真起点被误丢）。
**正确做法**：用 `sampleCandidateBiome` 已有的 **14 高度取样表**，取 structure set 内任一结构的 allowed biomes 并集，**全部高度都被拒才否决**。

**验收**：`structure resolutionMs` 从 **74 s → < 20 s**；`emptyResults` 占比不降（否决的都是真空）。
**先上计数模式**（只测不拦，`wouldRejectNonEmpty==0` 才允许真开），同旧版 R-07 的验收口径。

### 阶段 4：真 Finsler 接入 FMM（质量主线）

**改什么**：`FastMarchingSolver` 的慢度从 `isotropicCost` 换成 `cost(dirX, dirZ)`（4 邻域方向已知）。
**难点**：各向异性 Eikonal 需要 Ordered Upwind 类方法，不能直接套现有 Godunov。
**验收**：锯齿幅度 ±8 → ≤±2；`SawtoothMetric.flipsPer100` 显著降；`FinslerMetric.cost()` 不再零调用。

### 阶段 5：弹性带接障碍投影（质量主线收尾）

**改什么**：`ElasticBandSolver` 每轮迭代后把穿入 `ObstacleField` 的点投影回外。
**验收**：弹性带不穿建筑；替代旧版 8 个后处理 pass（`S5-POSTPROCESS-LEDGER` 里的 35 个方法随旧链路消失）。

### 阶段 6：ModeDpSolver + BuildPlan 接线（结构收尾）

- `ModeDpSolver` 桥隧联合 DP 接生产（内核已对拍过）；
- `BuildPlan` 替代「判定/施工交织」（S2 的尾巴）。
