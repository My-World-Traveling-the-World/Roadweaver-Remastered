## 三、之前做过的重制功能（当前仍成立）

- 网络拓扑：N 次场求解 → GeodesicMatrix → MinimumSpanningTree。
- 单路：FastMarchingSolver → pathTo → ElasticBandSolver.smooth。
- FinslerMetric.cost 已由 FMM 按 x/z 方向实际调用，不是死方法。
- 已完成坐标统一、边级障碍采样、源点不可达容错、FMM预计算与目标早停。
