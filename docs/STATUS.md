**配置和 UI。** 地图复用同快照最近两档折线，平移每帧仍查视口；Xaero 实际叠图与帧时待测。旧势场 A* 的部分配置键仍为了兼容保留；界面标记不生效。客户端直连部分业务实现是存量债务，新增跨层依赖由架构守卫约束；旧版 UI 真机验证不能代替当前界面验收。

**性能证据的范围。** 区块编译按扩张包围盒交区块扫描，路权匹配按 X/Z 分桶；FMM 已对拍新旧堆的格值和点序，远目标离线夹具的每次分配中位数从 4.49 MB 降至 2.28 MB。[HANDOFF](HANDOFF.md) 第 3、4、9 轮有样本和耗时。这些数据不代表进档速度、TPS、帧时间或区块尾延迟。

**对照基线。** 旧版用来核查可见能力和再现退化；历史 57 次真机观测和旧发布件只说明当时采样，当前二进制仍需[刷新样本](VALIDATION.md)。
