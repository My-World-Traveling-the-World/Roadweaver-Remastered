# RoadWeaver 当前实现

普通道路使用 PIPELINE 路网和 BAND 寻路。先从结构候选和粗地形确定连线，再按走廊精细采样，验证剖面和施工占地。后处理保持道路宽度、坡度、桥头和保护列；长桥保留正弦弯。

- **坡道、桥和隧道**：优先可建陆路，纵断面拒绝后尝试局部绕行；同端点、坡度和占地仍需全部验证。
- **结构和路网**：村庄按包围盒保护；普通道路确认有局部且不可绕的占地冲突时可留短缺口。道路能合并进既有路网，并在符合高度条件时共用路段。
- **游戏功能**：H 路网地图、手绘路线、路牌和装饰；规划和施工记录按存档保存。
- **联动**：合装兼容版本时河流 → 长城 → 道路；没有长城时河流 → 道路。只玩道路时安装道路和一份云游四海世界生成 API。

开局预读本存档的道路索引和施工台账，并按顺序等待已安装的河流、长城就绪。收集结构端点之后，用粗地形代价选边并规划粗走廊。默认沿走廊精采，求出施工站列、纵断面及桥隧，再合并路口并验证最终占地。H 地图读取已发布的计划。实际落块由已加载的 FULL 区块回填及后续生成完成，可通过施工台账和方块确认。

验证、成品和安装状态分别见[交接](HANDOFF.md)和[发布台账](RELEASES.md)。实地连通率和耗时需同种子实机比较。
