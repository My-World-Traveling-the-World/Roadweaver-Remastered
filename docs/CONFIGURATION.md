# 新版道路配置

本页描述2026-11-21配置改造后的实现。旧专项审查保留为修复前证据，不能再用其中“193项、155个控件、12页”描述当前菜单。

## 分类与编辑

196个持久配置项由同一份元数据生成菜单，按“所属子对象.字段”唯一绑定，避免不同对象的enabled相互覆盖。基础项直接展示，高级项与专家项默认折叠。结构选择器和材质预设编辑器继续保留独立入口。

| 菜单 | 主要内容 |
| --- | --- |
| 预热与规划 | 开局范围、动态规划、拓扑补连、等待预算 |
| 结构与避让 | 结构预测、筛选、村庄裁切、保护策略 |
| 地形与坡度 | 剖面、挖填、限坡、绕行、局部修复 |
| 桥隧与过水 | 桥、隧道净空、过水修复、桥灯 |
| 路面与装饰 | 道路开关、宽度、材质、清障、路牌和灯 |
| 路边建筑 | 路边结构与村庄的密度、间距和施工限制 |
| 性能与调度 | 工作池、后台预算、手绘优先、粗采样GPU策略 |
| 地图与界面 | 地图缓存、预览、调试及编辑器行为 |

菜单编辑独立快照，取消不会提前修改正在使用的配置。确认保存时校验并一次发布；后台任务仍使用各自快照。参数说明与范围、单位在同一个提示中显示。部分选项只影响对应功能开启后的分支，不承诺任意场景下改变都可见。

## 新开放的控制

| JSON键 | 默认值与范围 | 实际作用 |
| --- | --- | --- |
| pathfindingCost.finslerGradeWeight | 1；0..100 | Finsler坡度权重；影响拓扑计价与逐路选线 |
| pathfindingCost.finslerObstacleWeight | 4；0..100 | 逐路选线的软避障权重；设0不关闭硬保护 |
| pathfindingCost.elasticBandStiffness | 1；0.01..100 | 弹性带保形强度；增大更倾向保留输入路径 |
| bridge.lightIntervalBlocks | 16；0..2048格 | 模板桥额外道路灯的纵向间隔；0关闭这些额外灯，不删除模板自带灯 |

默认数值沿用改造前的数学内核与灯间隔，不以配置改造调整桥、隧道和道路几何。前三项已进入实际算法身份与规划身份。桥灯改变后不自动重建已完成桥梁。

## 范围、删除项与缓存

- 开局半径1..4096区块；动态规划半径1..2048区块。两者的预算用途不同，动态菜单不再允许填写保存后会被夹到2048的4096。
- 道路宽度菜单使用1..15的奇数；每两段最大坡度1..8，关闭限坡使用独立开关。0不再作为“无限坡度”输入。
- 等待超时为0或至少10000毫秒；局部修复聚类半径为0或8..128格。菜单会拒绝这些区间中的无效值，成对参数在保存时统一归一化。
- JSON浮点设置也必须有限；NaN和正负Infinity恢复该项默认值，不能绕过菜单把非数值送入搜索。
- 地形10项已纳入两种规划载荷。改变绕行、挖填、海底策略会改变相关缓存身份；线程和显示预算不据此让道路形态缓存失效。已有道路不会因为保存配置自动改建。
- 删除不生效的openclAccurateSamplingEnabled及历史generationThreads、旧坡度惩罚的迁移逻辑。新版只识别当前字段，旧未知键由GSON忽略，随后保存不再写出。
- 精确高度采样固定CPU，菜单展示只读解释；粗地形GPU开关、设备偏好、批量门槛和并发控制仍有效。此改造没有重新开启曾失败的精确GPU采样。

## 验证口径

回归直接枚举持久字段并调用真实绑定setter，检查196项各有唯一绑定、独立编辑、JSON/任务快照往返、数值端点、双语标题说明与单位；新增算法参数还驱动真实BAND、拓扑和模板桥写块入口。源码接线守卫只证明Fabric入口使用了这些绑定，不代替游戏中的实际窗口和布局验证。

本轮没有逐项真机A/B或帧时测量。高级参数不是越大越好，现有默认值保留；实际调参后的观感、整合包负载和热加载效果仍需游戏验收。变异记录和最终构建结果见[交接台账](HANDOFF.md)。
