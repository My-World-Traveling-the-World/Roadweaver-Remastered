# RoadWeaver 重制版的下一阶段

2026-11-15｜重制版基线 818b076，本轮生产提交 3a4327a、b12307f。旧版对照：roadweaver 的 refactor/structure-20261112@2c6547a。

旧版用来查施工承诺和功能退化。重制版的评价标准是：更常交付可建、可通行、能共享关键基础设施的路网；减少无用采样、寻路和区块任务等待。

| 范围 | 旧版 | 重制版要怎么超越 |
|---|---|---|
| 选线 | 势场 A* 对每条路扩展节点，地形、群系、避让、优惠和形状旋钮混在步进代价里，最后再修形 | 保留 FMM、DP 和弹性带；明示硬通行约束，记录并校准施工代价，不再叠旧版权重 |
| 选网 | 成路后再判并排、共用、合流 | 测地拓扑先选端点边，但 PipelinePlanner 传入 ObstacleField.NONE。下一步应让能否建造、能否共用渡口影响入选 |
| 施工 | 模板和程序化建造桥梁、隧道、陆地铺设与 NETWORK_REUSE | 两版调用均存在，复用既有建造能力，把同一份终态路线及区块占地交给施工 |
| 性能 | 历史的 215 秒来自旧版逐路搜寻的现场记录 | 不能与本轮纯内核毫秒数直接比较。应在同一存档、同一组连接拆分采样、拓扑、单路、区块编译和落块耗时 |

## 推荐顺序

1. **先修坐标口径（可离线）。** ArrivalTimeField.pathTo 从真实终点坐标开始按 step 回溯，读时间时却映射到吸附格，整条中间线带上终点余数。平地、step=8、源 (8,8)、终点 (34,19) 的实跑中，终点格为 (32,16)，返回 [(10,11),(18,11),(26,11),(34,19)]。先按整数网格坐标回溯，再由 BandRouteSolver、RoadPipeline 将现实端点作为独立连接边加回并验约束。用非对齐、负坐标、同格、紧贴保护格和双向用例验收；钉住网格对齐样本。
2. **按可建性选网（先影子评分）。** PipelinePlanner 当前用高度和轴向坡度选树，Road 在后段才做桥隧、挖填和保护校验。先并排记录候选的测地分和施工分：统计跨水宽度、保护占地、预计挖填；只对入选边和有限候补精算，失败用候补修复分量。首批夹具固定「近但难建」「两线能共用渡口」；比较施工后可通行道路、绕行、平行桥与挖填量。树无环不能证明地理路线不交叉。群系成本应校准为新版附加代价；大树接已有预留事实，先测命中，避免群系预筛误删结构。
3. **只决定一次横向几何（离线后真机 A/B）。** 分离选线与施工栅格化，先试只取消第二次陆地 relax；保留桥头加密、长桥正弦、保护列、道路宽度和站距约束。同一路径回放比较保护缺口、曲率、站距、桥头和落块；不能仅凭一次离线通过改默认。
4. **盯尾延迟（可离线起步）。** 先记录每路冻结格、队列入队和峰值、各阶段 p50/p95、区块任务最长等待。若队列分配主导，试原始数组小根堆，先等价复刻同权顺序并逐位对拍；若采样主导，优先在同一地形上下文共享只读瓦片。只有数据指向候选图过大才试分区和稀疏邻域，并复核合法替代边和连通性。
5. **分开道路身份和施工完工（先做重开对拍）。** PathFeature:241–242 用道路指纹判完工；RoadFingerprint 不读 targetY、spans 或占地列。保留现有身份和 schema 3，另外定义完工内容的比较策略。用同身份改坡或跨度、未改道路不重铺、现有台账重开验收；更新已经铺好的真实区块前用存档副本。
6. **更完整的方向代价（有 A/B 再设默认）。** 当前 x/z 轴向慢度不包含斜坡交叉项。先量化旋转后的同一斜坡、等高线和窄山口的方向误差，再试更丰富的迎风模板。验收看曲率、最大坡度和施工代价是否改善，保护冲突和尾延迟是否增加。

本轮保持 ProfileDpSource.crossing、跨度回写默认值、长桥正弦、村庄包围盒、QualityGate 阈值与存档格式。纯内核数据不外推世界加载和帧时间。现场样本应分首次生成、已有存档重开、Chunky 同时运行；分别记录计划、通过校验及实际落成的道路。
