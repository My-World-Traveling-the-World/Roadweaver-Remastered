## 1. 河流：去掉重复几何工作

入口：`streams-reflowing-src/.../core/river/NearestRiverIndex.java:417`；新组件`RiverCandidateCollector.java:12`。

一个河段会登记进多个空间桶。原冷查询拼接M条桶记录，每个重复编号都再次计算包围盒/投影；热缓存还先排序全部M条，再去重。

新实现收集时以河段编号的位集去重，仅第一次出现进入候选。用分字代次戳延迟清空，避免每次查询全清历史最大河网范围；回卷有专门清戳守卫。冷查询保留首次桶次序，热缓存仍对唯一编号排序。复杂度是收集O(M)、热排序O(U log U)，不再对M个重复项排序或重复投影。

## 2. 道路：利用二站坡度约束的区间结构

真实调用：`TargetProfileSolver.java:45`的`ProfileDpSource::solve`→`ProfileDpSource.java:260`→`ProfileDpSolver.java:291`。新组件`ProfilePairTransitions.java:8`。

令当前高差为d、前一高差为pd，状态范围均为[-L,L]。二站约束为：

```text
|d + pd| ≤ L
d ≥ 0：pd ∈ [-L, L-d]，即前缀
d < 0：pd ∈ [-L-d, L]，即后缀
```

对每个前一高度，一次前缀扫描、一次后缀扫描，就能求出所有后继高差的最优前驱。无需逐个后继重新扫描全部前驱。D=2L+1时，计算从O(nHD²)降为O(nHD)。

保持了原首对dummy状态、maxStep、窗口、钉住、缺省代价和不可行语义。旧算法从小下标选择同价父节点，后缀反向扫描必须额外处理同价更新；INF/NaN不能制造父节点。测试不仅比较总代价，还比较每个回溯高度和代价位模式。

新增5项包括800组随机窗口/钉住/缺代价、70组同价平台、非有限值/首对边界，并用60组独立穷举检查最优代价。

| --- | --- |
| 0 | 2.5152→1.3993 |
| 1，默认小窗口 | 3.4444→2.7456 |
| 2 | 4.3447→3.2729 |
| 4 | 7.8927→5.3569 |

新旧分配字节相同。`ProfileDpSolver.java:276`仍保存O(nHD)的完整int父表，本轮没有降低回溯内存。没有改变crossing、桥隧模式选择、双平滑或长桥正弦。
