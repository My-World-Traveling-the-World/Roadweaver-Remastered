## 一、村庄判据与建筑冲突

### 过路村庄按聚合盒裁开
- **做什么**：路路过非端点村庄时，盒内站点全部落成缺口（不铺装、不打 stamp、不放路灯、不重试）。
- **关键类**：`SAS:4415`（掩码）、`:4447`（盒聚合）、`:4458`；生产端 `:1603`。
- **关键参数**：`passThroughVillageClipping=true`（`config/sub/PlanningConfig.java:57`）；施工带 `CONSTRUCTION_BELOW=2`/`ABOVE=6`（`SAS:109`）；`VILLAGE_GAP_BELOW_TOLERANCE=16`（`:117`，**仅声明无消费点**）。
- **算法核心**：按 owner 聚合「非端点 + 村庄类」盒（`:4447`），逐站判 XZ（`:4429`）；0.9 起**取消 Y 判定**，否则掠过村子上/下方的路会被放过（`:4424`）。
- **⚠️ 降级**：配置抛异常 → **全 false 掩码**（`:4417`）；`passThroughVillageCrossings` 开关关/快照空返回 **`-1`**（`:1661`，真 0 次是 `0`）；`isVillageStructure` 只看 id 含 `village`（`:3463`），改名村庄不参与。

### 端点村庄落地裁切
- **做什么**：路可进端点村庄空地，但须在「第一个离开聚合盒的站点」落地，否则会开到村中心。
- **关键类**：`:1524`（入口）、`:4333`、`:4382`（找盒外站）、`:4472`（端点村庄盒）、`:4521`。
- **关键参数**：`ENDPOINT_VILLAGE_GROUP_RADIUS_BLOCKS=96`（`:105`）、`ENDPOINT_REPLACEMENT_MATCH_BLOCKS=24`（`:137`）、至少留 **2** 站（`:4368`）。
- **算法核心**：首/末站贴到 from/to 后双向找盒外站（`:4382`）；全程在盒内才退化到「第一栋建筑前一站」（`:4521`）；不足 2 站 → `null`（`:4368`）。
- **⚠️ 降级**：段数 <3、`endpointOwners` 空、`boxes` 空 → **原样返回**（`:4336`），与「不需裁切」同形。

### 建筑冲突判定：三层严格度 + 桶索引
- **做什么**：同一快照三种口径：只认 verified 建筑 / 含未解析与强制竖直 / 只认端点建筑。
- **关键类**：`:4195`（`findCollision`）、`:4220`、`:4241`、`:3514`/`:3531`、`:3546`（`occupancyKind`）。
- **关键参数**：`roadRadius=ceil(roadWidth/2)`（`:3971`）；`MAX_CACHED_BLOCKS=200_000`（`:3559`）。
- **算法核心**：桶索引只取本 chunk 候选（建桶按 `±roadRadius` 展开，`:3998`）；端点 owner 跳过（`:4253`）；`forcedVerticalOwners` 走「够到盒底即算撞」（`:4201`）；实际由模板方块回答。
- **⚠️ 降级（最隐蔽）**：`occupancy==null` 时 `intersects`/`intersectsSolid` **直接 `false`**（`:3522`、`:3532`），而 `isVerifiedBuilding` 只认 `"template-blocks"`（`:273`）：模板解析失败时**盒子在、日志静、对规划校验无效**。

### 村庄群聚合盒（HARD 模式，出厂不生效）
- **关键类**：`:1428`、`:4153`、`:1455`、`:1415`、`:1381`。
- **关键参数**：`VILLAGE_CLUSTER_MIN_PIECES=3`（`:1438`）、`CLUSTER_BOX_CACHE_CAP=16`（`:1439`）、默认 `PENALTY`（`:1383`）。
- **算法核心**：按 owner 去重收 verified 建筑（端点豁免）→ ≥3 栋才 union；缓存键是快照实例，不可变故永不失效（`:1444`）。
- **⚠️ 出厂**：`PENALTY` 下 `blocksPlanningObstacle` 首行 `return false`（`:1417`）。

## 二、`PlanningSnapshot`：准备 / 缓存 / 失效 / 线程作用域

### 快照对象与键
- **做什么**：把一条连接沿途的结构占用冻结成不可变对象，供多 worker 并发只读。
- **关键类**：record（`:3935`，字段 `boxes/boxesByChunk/endpointOwners/resolvedStarts/coveredCandidateChunks/roadRadius`）、`EMPTY` `:3942`、`forRoute` `:3962`、`merge` `:4023`。
- **关键参数**：`roadRadius` 实算 `:3971`；端点扩权 `:3993`；桶展开 `:3998`。
- **算法核心**：键 = 维度 + seed + **两端点 2D 长整且已排序**（`:3175`）；`merge` 四项未变即**返回旧实例**（`:4053`），按实例缓存不因无变化 merge 失效。

### 三个准备入口 + 圆形探针
- **做什么**：规划前备整片；定线后只补走廊；修坡/绕行只补局部圆。
- **关键类**：`:551`（全区）、`:590`（走廊）、`:603`（单路）、`:641`（圆形）、`:632`（半径夹紧）、`:1184`（线程约束）。
- **关键参数**：`PLANNING_CORRIDOR_RADIUS=192`（`:118`）、`STRUCTURE_START_REACH_CHUNKS=11`（`:123`）、`MAX_CIRCLE_PROBE_CHUNKS=256`（`:625`）、`AVOIDANCE_PREDICTION_TILE_CHUNKS=16`（`:125`）。
- **算法核心**：候选起点（`:2296`）→ 瓦片预测（`:2201`）→ 分批解析（`:2495`）→ 写快照（`:1278`）；圆形入口用**合成探针路径**枚举 chunk 且不落盘（`:664`）；非主世界/开关关/`server==null` 直接返回 `completedFuture(null)`（`:561`、`:681`）。

### 容量、淘汰、失效
- **关键类**：`SAC:29`（LRU 8192）、`:31`；`SAS:277`（`invalidate`）、`:311`（`discardPlanningSnapshot`）、`:2939`、`:4694`。
- **关键参数**：`PLANNING_SNAPSHOT_CACHE_CAPACITY=2048`（`:132`）、`PREPARED_START_CACHE_CAPACITY=32768`（`:133`）、`OBSTACLE_TILE_CACHE_CAPACITY=8192`（`:135`）。
- **算法核心**：容量表各配插入顺序队列、满即从头淘汰；`discardPlanningSnapshot` 同时取消该路由在飞走廊（`:311`）；开局期起点钉住（`:2745`），worker join 后才并回主表（`:2939`）。
- **⚠️ 降级**：淘汰只累加 `PREPARED_CACHE_EVICTIONS`（`:4730`）**无日志**；`invalidate` 只清单 chunk bbox（`:277`），**不动**该 chunk 所属路由快照；Chunky 让位时明确**不释放**结构 bbox（`runtime/CacheManager.java:78`）。

### 线程作用域（ThreadLocal）
- **关键类**：`SAC:50`（`ACTIVE_PLANNING_SNAPSHOT`）；`SAS:1383`（`BUILDING_OBSTACLE_MODE`）、`:3483`（`PlanningScope`）、`:1338`。
- **关键参数**：无配置项；`additionalRoadRadius` 仅精修证明实际路面宽一列时临时加（`:1338`）。
- **算法核心**：激活时放入该路由快照（缺省 `EMPTY`），返回句柄恢复上一份（上一份 null 则 `remove`，`:1347`）；A* 只读 `shouldAvoidPlanning`（`:1356`）。
- **⚠️ 降级（最危险）**：**忘记包 scope，`shouldAvoidPlanning` 恒 false**（`:1356`），A* 看到「没有结构的世界」，不报错只把路修进村。

## 三、结构预测

### `predictStructuresInRect` 系列
- **做什么**：不加载 chunk，按 placement 数学规则 + 群系采样预测结构位置。
- **关键类**：`SP:51`、`:138`、`:280`、`:435`（AroundSpawn）、`:622`（过滤器）。
- **关键参数**：`predictRadiusChunks=1024`（`config/sub/StructurePredictionConfig.java:15`；`RC:225`）；白名单 `["#minecraft:village"]`（`:17`）、黑名单空（`:18`）。
- **算法核心**：`ConcentricRings` 取环位（`:337`）；`RandomSpread` 按 spacing 枚举 region + `getPotentialStructureChunk`/`isStructureChunk` 双校验（`:392`）；其它放置仅 `scanGenericPlacements` 时整矩形扫（`:365`）。
- **⚠️ 降级**：`isOverworld` 假 → `List.of()`（`SP:553`）；上游 `SIS:51` 只在 `claimScanWindow` 成功时真扫，否则**直接回读旧预测**（`:109`）。

### 避让专用预测与群系预筛
- **关键类**：`SP:156`、`:270`（面过滤）、`:244`（`biomeWouldReject`）、`:558`（多高度取样）；消费者 `SAS:2201`、探针 `SAS:2773`。
- **关键参数**：`AVOIDANCE_PREDICTION_TILE_CHUNKS=16`（`SAS:125`）；矩形半宽 `192+11×16`（`SAS:2204`）；探针属性 `roadweaver.biomePrefilterProbe`（`SAS:145`，默认开）。
- **算法核心**：只按 id 子串排除 `monster_room`/`nether_fossil`（`SP:270`），候选须在矩形内且 `isStructureChunk` 真（`:210`）；`biomeWouldReject` 取 allowed biomes 并集、只在 quart(64) 单点取样（`:250`），与多高度扫描**不同口径**。
- **⚠️ 现状**：避让链路**没有预筛消费者**；注释口径 4374 起点里 91.4% 解析为空（`SP:229`）；开启门槛是 `BIOME_PROBE_REJECTED_NONEMPTY==0`（`SAD:27`）。
- **⚠️ 降级**：非主世界 → `List.of()`（`SP:161`）；`biomeWouldReject` 非 RandomSpread/biomes 空/抛错 → `null`，必须当「不挡」（`:245`）。

### 放置数学预筛 + 护栏、结构验证
- **关键类**：`SAS:932`、`:959`（护栏）；`SVS:41`（验证）；调用方 `SIS:51`。
- **关键参数**：`PREFILTER_GUARD_SAMPLE=64`（`SAS:919`）、开关 `planning.prefilterStructureStarts=true`（`config/sub/PlanningConfig.java:230`）。
- **算法核心**：`getPotentialStructureChunk` 必须严格等于候选（`SAS:944`）；护栏抽最多 64 个被跳过候选双跑，出盒子即**永久关预筛**（`:996`）；验证按 id 记忆化后 `START_PRESENT`/`CHUNK_LOAD_NEEDED` 均算通过（`SVS:151`）。
- **⚠️ 降级**：预筛遇非随机散布/配置异常放行、护栏抛错也关预筛（`SAS:944`、`:1012`）；验证遇非 `ServerChunkCache`/scanner 抛错/id 无注册 → **原样放行**（`SVS:49`、`:115`）：「无法验证」=「通过」。
- **⚠️ 实际无效**：预测候选本身就是 potential chunk ⇒ 判据恒真，`prefilterSkipped` 长期 0（`SAS:2767`）。

## 四、结构起点解析与 owner

### `PreparedStartKey` 与精确起点解析
- **关键类**：`SAS:3119`（键）、`:2405`（窗口）、`:2495`（批）、`:2557`（在飞合并）、`:2735`（存入）、`:2797`（读取）。
- **关键参数**：`BATCH_SIZE=16`（`:126`）、`WINDOW=2`（`:128`）、`PREPARED_START_CACHE_CAPACITY=32768`（`:133`）。
- **算法核心**：起点按窗口（16×2 列）分批；先查 pinned→主表，miss 才真解析，同键请求在 `IN_FLIGHT_STARTS` 合并（`:2557`）。
- **⚠️ 降级**：解析返回 `null` → 抛 `IllegalStateException`（`:2739`）；解析出**空**则把空列表当有效结果缓存（`:2741`），空起点不再重算且与「确实没有」同义。

### 端点 owner 解析（四段递进）
- **关键类**：`SAS:3213`、`:3288`、`:3395`（推断）、`:3455`（family）、`:1150`（严格匹配）。
- **关键参数**：`ENDPOINT_REPLACEMENT_MATCH_BLOCKS=24`（`:137`）、`ENDPOINT_OWNER_INFERENCE_MATCH_BLOCKS=16`（`:143`）。
- **算法核心**（均要求唯一最近）：① 命中已核验位点 → `(start chunk, registry id)`（`:3309`）；② 同 id 且盒含端点（`:3333`）；③ family 相同 + ≤24 格（`:3358`）；④ 同 family + verified + ≤16 格（`:3395`）。
- **⚠️ 降级**：四段全失败 → **不加该端点 key**（`:3391`），该结构不再豁免、路绕它；只有成功分支有 info（`:3300`），**无「未确定」告警**；等距多义主动放弃（`:3333`）。

### 未知端点过滤
- **关键类**：`SAS:1020`、`:1128`、`:4277`（`villageOwnerAt`）、`:1164`；**唯一调用点** `IGM:450`。
- **关键参数**：`UNKNOWN_ENDPOINT_FILTER_MAX_PER_ROUND=4`（`:907`）。
- **算法核心**：两条同时成立才过滤 —— 端点为「未知」（只看是否命中已核验位点，`:1128`），另一端点 chunk 与 id **精确等于**该村庄 owner（`:1150`）；阀一单轮 >4 条放弃（`:1097`），阀二端点 0 连接放弃（村内连接豁免，`:1104`）。
- **⚠️ 降级**：配置读异常 → 不过滤（`:1026`）；快照缺失 → 保留该连接（`:1041`）；`villageOwnerAt` 多义 → `null` → 不过滤（`:4290`）。

## 五、路口合并 / 辫状 / 共享跨越

### 批次合并
- **关键类**：`ERJ:100`、`:718`、`:738`（`plausibleDonor`）、`:677`（单供体）、`:901`（交点 span）。
- **关键参数**：`MAX_JUNCTION_CONSTRUCTION_OVERHEAD=17`（`:46`；`RC:427`）、`JUNCTION_REFINE_TIMEOUT_MS=120_000`（`:59`）、批量只收 ≥5 站（`:107`）。
- **算法核心**：单供体选择（`:677`）→ `plausibleDonor`（包围盒 gap ≤12；已有复用候选时需共享 owner，`:738`）→ 真接、失败退裁剪（`:688`）→ 只在「复用站更多或同复用更短」时替换（`:677`）；交点写 `JUNCTION_ANCHOR`，隧道侧 `TUNNEL_JUNCTION`（`:901`）。
- **⚠️ 降级**：配置异常 → `none()`（`:338`）；读不到包围盒 → `true` 宁可多算（`:444`）；精修超时/失败保留原候选（`:567`）。

### 辫状预检与强制改道
- **关键类**：`ERJ:328`、`:467`（改道）；`RBD:58`（`MIN_RUN=6`）、`:62`（`MAX_DISTANCE=12`）、`:64`（`MIN_DOT=0.75`）。
- **关键参数**：`braidRerouteRadius=18`、`braidRerouteMaxLengthRatio=1.5`（`RC:276`、夹紧 `:256`）；`BRAID_BAN_STATION_MARGIN=4`（`ERJ:276`）、`REROUTE_MIN_LENGTH_RATIO=0.6`（`:286`）。
- **算法核心**：全批次**无条件两两**扫（含已落盘作「前者」），先包围盒预筛（`:444`）再逐站判；改道在重叠段 ±4 站禁令下重算并两端「挖洞」（`:480`）；四道门：站数 ≥`max(12,0.6×原)`、≤`ratio×原`、校验通过、改后不再 braid（`:505`）。
- **⚠️ 降级**：拿不到 ≥2 站、禁令空、重算抛异常、四道门任一不过 → **保留原路**；0.9.028 前静默，现补 info（`:500`）。

### 共享跨越（桥）与共享端点复用
- **关键类**：`pathlogic/bridge/BridgeShareService.java`（275 行）`applyInPlace`（调用点 `ERJ:152`）；`ERE:41`、`:105`、`:130`。
- **关键参数**：`bridgeShareRadius` 直接读 `ConfigService`（`ERJ:154`）；`APPROACH_THRESHOLD=48`（`ERE:41`）。
- **算法核心**：桥按半径归并同批次 span 并吸附端点/甲板高度（口径 `missingEndpoints/recovered/absorbed/skippedInvalid` 同行打印，`ERJ:258`）；端点复用跳过已完成/失败/手动端点（`ERE:42`），未落地还要 ≥4 站规划路径防断头（`:119`）。
- **⚠️ 降级**：`skippedInvalid` 只计数不阻断；`ERE` 自身路径缺失或 <4 站 → `null`（`:41`），`hasPlannedPath` 抛错 → `false`（`:124`）。

## 八、端点处理

### 端点村庄分组半径 96
- **关键类**：`SAS:4606`（`expandEndpointVillageOwners`），由 `forRoute` 调用（`:3993`）。
- **关键参数**：`ENDPOINT_VILLAGE_GROUP_RADIUS_BLOCKS=96`（`:105`）。
- **算法核心**：先收端点 owner 的村庄 family（末段名，`:3455`），再把「family 命中 + verified + 距 from/to 之一 ≤96 格」的 owner 加入豁免（`:4636`）；注释（`:4615`）记：旧实现只按距离聚合，会把相距 73 格的两个独立村庄当同一群而整片切穿（T-35）。
- **⚠️ 降级**：无村庄 owner → 返回原集合（`:4612`）。

### 端点裁剪
- **关键类**：`SAS:1543`（`stopAtEndpointBuilding`）、`:4082`；`SROS:39`（`trimPathNearStructure`）。
- **关键参数**：村庄端点用**包围盒**裁、非村庄用偏移量（`villageRoadOffset=60`、`otherStructureRoadOffset=15`，`StructurePredictionConfig:19`；`RC:221`）；`MATCH_TOLERANCE_BLOCKS=16`（`SROS:29`）。
- **算法核心**：找首/末不在端点建筑内的站并裁剪；整条被一栋建筑吃掉 → warn + `return null`（`:1555`），不足 2 站同样；偏移版按欧氏距离 ≥offset、村庄版按 `!box.isInside(pos)` 找首站（`SROS:77`）。
- **⚠️ 已废弃入口**：`SROS:35` 的 `adjustEndpoint` 标 `@Deprecated` 且**恒等返回入参**，若仍有调用方则端点偏移实际不生效。

### 端点守卫（不接成断头路）
- **关键类**：`SAS:1164`（`leavesEndpointWithoutConnection`）、`:1699`（端点缺口样式）；调用 `IGM:571`。
- **关键参数**：`ENDPOINT_PROTECTED_GAP_RADIUS_BLOCKS=32`（`:106`）。
- **算法核心**：按 2D 位置键统计 kept 侧连接数，被过滤连接任一端点计数 0 即整体回退（`:1164`）；`endpointOnlyProtectedGapPattern` 逐 span 取「两端到两端点的最小水平距离」，任一 >32 格即判否（`:1699`），从而「只有端点缺口」时不再替换拓扑。
- **⚠️ 降级**：无缺口/段数 <2/端点 null → `false`（`:1683`）。
