# 云游四海 · RoadWeaver 重制版

[English](README.md) | 简体中文

云游四海在村庄和已配置的结构之间自动规划并建造道路。本仓库是重制版，面向 **Minecraft 1.21.1、Fabric、Java 21**。

- 选线考虑地形和结构保护，施工可铺设普通道路、架桥、开挖隧道。
- 支持道路材料预设，以及路牌、路灯和路边装饰配置。
- 游戏内按 **H** 打开路网地图，可查看路线、手动建立连接。

地形模组会改变规划和施工的输入。整合包兼容性和实际运行耗时，以对应版本、存档的[真机验证](docs/VALIDATION.md)为准。

开发者从[文档导航](docs/README.md)开始；查当前实现看[开发现状](docs/STATUS.md)，查已有发布件看[发布台账](docs/RELEASES.md)。

上游 [RoadWeaver](https://github.com/shiroha-233/RoadWeaver) 有独立的 [Modrinth](https://modrinth.com/mod/roadweaver)、[CurseForge](https://www.curseforge.com/minecraft/mc-mods/roadweaver) 页面和 [Discord 社区](https://discord.gg/tUJMJkbbr2)。模组受 [Countered's Settlement Roads](https://modrinth.com/mod/countereds-settlement-roads) 启发，地图灵感来自 [RoadArchitect](https://github.com/FranckRJ/RoadArchitect)。
